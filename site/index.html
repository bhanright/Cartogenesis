How a world is made

  1. 01

    Plates and mountains

    Moving tectonic plates form mountain ranges, volcanic arcs and broad plateaus. Where plates pull apart, rift valleys can fill with water.

  2. 02

    Erosion

    Erosion reshapes the terrain. Slopes collapse, rivers carve valleys, and sediment builds floodplains, fans and deltas.

  3. 03

    Seas and ice

    Continental shelves lie along the coasts. Glaciers shape cold mountains, and ice sheets leave behind basins and lakes.

  4. 04

    Climate

    Seasons, ocean currents and terrain shape temperature and rainfall. Climate zones decide where forests, grasslands and deserts form.

  5. 05

    Rivers and lakes

    Water flows downhill into rivers, lakes and seas. In dry inland basins, evaporation can shrink a lake and leave salt behind.

  6. 06

    Realms and peoples

    Geography shapes borders and settlement. Realms follow rivers, coasts and watersheds, while peoples spread into familiar terrain and across political borders.

Features

Views
Fifteen views, including political borders, peoples, elevation, biomes, seasonal temperature and rainfall, tectonic plates, ocean currents and winds.
Styles
Twelve map styles, including Atlas, Vellum, Ink wash, Nautical, Pen and ink, Mars, Natural and a colour-blind-safe palette.
Themes
Seventeen interface themes, including light, dark, high contrast and colour-blind options.
Editing
Edit generated names and borders. Your changes are saved with the world.
Saves
Save a world and reopen the same file in the browser or the desktop app. In Chrome and Edge the browser's library can live in a folder on your device, including one a sync service keeps in step.
Export
Export map images as PNG, WebP or JPEG, drawn at the world's true shape, or the data behind the map, one sample per cell: a 16-bit heightmap with its metre scale, and biome and realm index maps with their legends. The desktop app makes worlds up to 4096 × 4096, whose map image is 8192 × 4096. The browser, on a phone or a computer, stops at 2048 × 2048.
Resolution
Choose the world's resolution. Higher settings add detail and need more memory; the browser starts at 512, the desktop app at 1024.
Acceleration
Optional graphics acceleration speeds up erosion and export rendering: WebGPU in the browser, OpenGL on the desktop.

Notes

Running it in a browser

Use a recent Chrome, Edge, Firefox or Safari. The first visit downloads the generator, about __BUNDLE_MB__ MB, and caches it; nothing you make is uploaded anywhere.

Saved worlds stay in the browser's own storage, or, in Chrome and Edge, in a folder on your device that you choose in the Library. The desktop app opens the same files; the browser opens the desktop's up to 2048.

Optional graphics acceleration uses WebGPU where the browser offers it.

Sizes, formats and speed

An export regenerates the world at the size you ask for, so the detail is real rather than enlarged. The map image is drawn at the world's true shape, twice as wide as it is tall: a 2048 world is a 4096 × 2048 picture. Larger worlds take longer and use more memory. The browser stops at a 2048 world, a 4096 × 2048 picture, for the world on screen and for exports. Larger worlds need the desktop app.

PNG keeps every pixel. WebP is smaller and softens thin rivers and borders slightly.

The Atlas is a work in progress

Today the Atlas lists a world's realms and landmarks and lets you rename them and place labels. Your changes are saved with the world. A later release, planned for 5.0, adds named continents, seas, bays, straits and ranges, with labels set out the way a printed atlas sets them.

Download and Installation

Choose your system for its files and how to install them. The browser version runs anywhere; the desktop app makes larger worlds.

MSI installer Portable zip

The portable zip installs nothing: unzip it and run Cartogenesis.exe. The MSI installer adds a Start menu entry. It is unsigned, so Windows shows a SmartScreen warning. If you trust the download, choose “More info”, then “Run anyway”.

  • Java is bundled, with nothing else to install.
  • Draws exported pictures on the graphics card where there is one, and runs erosion, ocean currents and the ice sheet on it when you switch graphics acceleration on.

The apt repository is recommended, so later releases arrive with apt upgrade. These three commands fetch the signing key, add the source line and install:

sudo curl -fsSL https://cartogenesis.com/apt/key.asc -o /etc/apt/keyrings/cartogenesis.asc
echo "deb [signed-by=/etc/apt/keyrings/cartogenesis.asc] https://cartogenesis.com/apt stable main" | sudo tee /etc/apt/sources.list.d/cartogenesis.list
sudo apt update && sudo apt install cartogenesis
.deb package Portable tarball

Or install the .deb with apt, or unpack the portable tarball and run it.

  • Java is bundled, with nothing else to install.
  • The open-source graphics stack (Mesa) was tested. The proprietary NVIDIA driver was not.
  • Saved worlds live in ~/.cartogenesis/worlds.
Open in the browser Web zip, to host yourself

Runs in a recent Chrome, Edge, Firefox or Safari. Nothing is installed and nothing you make is uploaded: worlds are kept in the browser's own storage or, in Chrome and Edge, in a folder you choose, the same files the desktop app keeps.

  • Makes worlds up to 2048 in the browser; the desktop app goes to 4096.
  • On a phone, worlds generate at 512 by default, and 2048 works.
  • To host it yourself, serve the web zip's contents over HTTPS.
