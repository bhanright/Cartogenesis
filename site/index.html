How a world is made

  1. 01

    Plates and mountains

    Moving tectonic plates form mountain ranges, volcanic arcs and broad plateaus. Where plates pull apart, rift valleys can fill with water.

  2. 02

    Erosion

    Erosion reshapes the terrain. Slopes collapse, rivers carve valleys, and sediment builds floodplains, fans and deltas.

  3. 03

    Seas and ice

    Continental shelves lie along the coasts. Glaciers shape cold mountains, and ice sheets leave behind basins and lakes.

  4. 04

    Climate

    Seasons, ocean currents and terrain shape temperature and rainfall. Climate zones decide where forests, grasslands and deserts form.

  5. 05

    Rivers and lakes

    Water flows downhill into rivers, lakes and seas. In dry inland basins, evaporation shrinks lakes, and some dry out completely.

  6. 06

    Realms and peoples

    Geography shapes borders and settlement. Realms follow rivers, coasts and watersheds. Peoples spread through land like their homeland, whatever the borders.

Features

Views
Fifteen views, including political borders, peoples, elevation, biomes, seasonal temperature and rainfall, tectonic plates, ocean currents and winds.
Styles
Twelve map styles, including Atlas, Vellum, Ink wash, Nautical, Pen and ink, Mars, Natural and a color-blind-safe palette.
Themes
Seventeen interface themes, including light, dark, high contrast and color-blind options.
Editing
Rename realms, capitals and landmarks, edit their details and notes, and place your own labels. Future updates will add a full atlas system for editing borders, landmarks and labels in more depth.
Saves
Save a world and reopen the same file later, with your edits and labels.
Export
Export the map as a PNG, WebP or JPEG image. You can also export the data behind it for other tools: a 16-bit heightmap with its scale in meters, and biome and realm maps with their legends. The desktop app makes every world at 1024, and its map images are 2048 × 1024 pixels.
Resolution
Every world is made on one grid of 1024 rows, each cell about 20 km across.
Acceleration
Optional graphics acceleration uses the graphics card to speed up erosion, ocean currents and ice sheets, through OpenGL on the desktop, and the desktop app draws exported maps on the graphics card.

Notes

The browser preview

The browser version is an older preview and is no longer updated: it runs an earlier generator than the desktop app, so its worlds differ from the pictures on this page. For the current version, download the desktop app.

The preview runs in a recent Chrome, Edge, Firefox or Safari. The first visit downloads the generator, about __BUNDLE_MB__ MB, and caches it; nothing you make is uploaded anywhere. The desktop app opens worlds saved in it.

Sizes, formats and speed

An export is the world on screen, one pixel to a cell. Map images are twice as wide as they are tall, so a world of 1024 rows exports as a 2048 × 1024 picture.

PNG keeps every pixel. WebP is smaller and softens thin rivers and borders slightly.

The Atlas panel is a work in progress

Today the Atlas panel in the app lists a world's realms and landmarks. You can rename them and place your own labels, and your changes are saved with the world. Version 5.0 is planned to add named continents, seas, bays, straits and mountain ranges, labeled the way a printed atlas labels them.

Desktop versionWindows · Linux

The desktop app makes larger worlds, up to 2048, or 4096 with 24 GB of memory or more, and spreads the work across your processor's cores. See the download section below for each system's files and how to install them.

Download and install

Choose your system to see its downloads and how to install them. The desktop app is the current version; the browser preview is an older one, kept online as it was.

MSI installer Portable zip

The portable zip installs nothing: unzip it and run Cartogenesis.exe. The MSI installer runs a wizard to install it in your chosen program directory like any other program. It is unsigned, so Windows shows a SmartScreen warning. If you trust the download, choose “More info”, then “Run anyway”.

  • Java is included, so there is nothing else to install.
  • Draws exported pictures on the graphics card where there is one, and runs erosion, ocean currents and the ice sheet on it when you switch graphics acceleration on.

The apt repository is recommended, so later releases arrive with apt upgrade. These three commands fetch the signing key, add the source line and install:

sudo curl -fsSL https://cartogenesis.com/apt/key.asc -o /etc/apt/keyrings/cartogenesis.asc
echo "deb [signed-by=/etc/apt/keyrings/cartogenesis.asc] https://cartogenesis.com/apt stable main" | sudo tee /etc/apt/sources.list.d/cartogenesis.list
sudo apt update && sudo apt install cartogenesis
.deb package Portable tarball

Or install the .deb with apt, or unpack the portable tarball and run it.

  • Java is included, so there is nothing else to install.
  • Graphics acceleration has been tested with the open-source Mesa drivers, but not yet with NVIDIA's own driver.
  • Saved worlds go in ~/.cartogenesis/worlds unless you choose another folder.
