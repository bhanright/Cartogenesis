# Design ledger

One row per piece of work that has landed: what changed in the generator, the interface or the
build, and the figures measured to show it. The chunk labels (D1, A4, F13, S2 and so on) are the
labels the code comments cite, so a comment that points at a chunk points at a row here.

The rows are in the order the work was planned, not in date order. Work that is planned but not yet
done is on `ROADMAP.md`; the physical rules the generator is judged against are in
`docs/GEOGRAPHY.md`, and the structural gaps still open are in `docs/REALISM_AUDIT.md`.
